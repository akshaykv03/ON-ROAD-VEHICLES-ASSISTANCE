# 🚗 On-Road Vehicle Assistance System  
*A Python + SQLite Web Application*

## 🔷 Overview  
The **On-Road Vehicle Assistance System** is a web-based platform designed to help stranded vehicle owners by connecting them with **nearby mechanics** based on their current location where the breakdown happened.  
The system offers real-time request handling, service provider matching, and location-based assistance to ensure quick roadside support.

---

## 🔷 Modules

### ✅ User Module (Vehicle Owner)
- Register / Login  
- Submit breakdown request (current location auto-detected or manually entered)  
- View list of nearby mechanics  
- Track request status  
- View assigned mechanic details  
- Rate & review the service  
- View previous service history  

### ✅ Service Provider Module (Mechanic / Tow Agent)
- Register / Login  
- Manage availability  
- View incoming service requests  
- Accept or reject requests  
- Update request status: *Pending → En Route → Completed*  
- View service history  

### ✅ Admin Module
- Manage users & service providers  
- Monitor all live service requests  
- View logs and system reports  
- Manage reviews and feedback  
- Admin analytics dashboard
